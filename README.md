# 🗳️ Voto Consciente — UNIRIO

Portal institucional do projeto de pesquisa e extensão da UNIRIO.

## Sobre o projeto

O **Voto Consciente** é um projeto de pesquisa e extensão da Universidade Federal do Estado do Rio de Janeiro (UNIRIO), vinculado à Escola de Ciência Política. Nossa missão é promover a educação política apartidária, fortalecendo a democracia por meio da informação clara, acessível e qualificada.

> "Três votos. Cada um com um papel diferente. Aprenda a escolher bem."

## Tecnologias utilizadas

- HTML5
- CSS3 puro
- JavaScript Vanilla

## Acessibilidade

O projeto segue as diretrizes **WCAG 2.2**, com:
- Navegação por teclados
- Alto contraste
- Ajuste de fonte
- Skip navigation
- ARIA labels
- HTML semântico
